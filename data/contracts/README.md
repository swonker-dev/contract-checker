# Демонстрационные трудовые договоры

В папке `correct` находятся десять договоров без намеренно добавленных нарушений
по проверяемым статьям ТК РФ. В папке `problematic` находятся десять договоров с
заранее известными дефектами. Все имена, реквизиты и контактные данные вымышлены.

Кейсы 06-10 используют более естественные и разнообразные формулировки. Они не
подгонялись под текущие регулярные выражения и нужны для проверки обобщаемости.

Кейсы 11-20 созданы как отдельный набор с новыми должностями, работодателями и
формулировками. В наборе `correct` нет намеренно внесённых дефектов, а набор `problematic`
содержит новые комбинации нарушений и неопределённых условий.

Первый сквозной прогон:

```powershell
python -m contract_checker analyze .\data\contracts\problematic\problematic_01_multiple_violations.docx
```

Генераторы набора находятся в `scripts/generate_demo_contracts.py` и
`scripts/generate_diverse_contracts.py`.
