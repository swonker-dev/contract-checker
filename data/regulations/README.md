# Нормативная база

В этой папке хранятся проверенные локальные копии выбранных нормативных источников.

Каждый активный JSON-файл должен содержать метаданные источника и массив `chunks`.
Файлы с суффиксом `.example.json` являются примерами и не загружаются в индекс.

Нормативный текст необходимо переносить из официального источника без пересказа.
Для каждой редакции следует сохранять дату действия и ссылку на источник.

При запущенном приложении редакциями можно управлять на странице
`http://127.0.0.1:8000/regulations`. При загрузке новой редакции прежняя редакция с тем же
`source_id` перемещается в `data/regulations/archive`. Индекс будет перестроен при
следующей проверке договора. В текущем MVP эта страница не имеет авторизации и
должна быть доступна только при локальном запуске.
