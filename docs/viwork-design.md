# Применение брендбука ViWork

Интерфейсы каталога, проверки договора, результатов анализа и нормативной базы
приведены к брендбуку ViWork версии 1.0 от 30.09.2026.

## Соответствие правилам

| Правило | Реализация |
| --- | --- |
| Фон страницы `#F3F4F6` и белые панели | Общие токены `--page` и `--card`, без градиентов и декоративных теней |
| Inter и запасной стек | Локальный вариативный Inter, затем Segoe UI, Roboto, Arial |
| Заголовки | 30 px / 600 над панелью, 24 px / 500 внутри панели, 20 px / 500 для блоков |
| Каркас | Белая шапка высотой 56 px и радиусом 12 px, боковая колонка 268 px |
| Логотип | Извлечён из предоставленного файла, высота 28 px, пропорции и цвета сохранены |
| Панели | Радиус 24 px, внутренние отступы 32 px, на формах рамка `#E5E7EB` |
| Кнопки | 38 px, основные действия 46 px, радиус 8 px, основная заливка `#047857` |
| Статусы | Пилюля с точкой и текстом; успех, предупреждение, ошибка и обработка имеют свои пары цветов |
| Недоступные действия | Прозрачность 45%, причина показана рядом или в статусе профиля |
| Фокус | Кольцо 4 px `rgba(5,150,105,.25)`, нативные `button` и `a` |
| Иконки | Линейные SVG, штрих 2 px; иконки меню 16 px |
| Числа | Форматирование `ru-RU` для размеров файлов |
| Мобильная версия | Навигация над контентом, перестроение колонок и адаптивные отступы |

В репозитории отсутствует код основного портала ViWork. Поэтому общий каркас
реализован для самостоятельного локального приложения с двумя существующими
разделами. Поиск, фильтры и дополнительные действия в шапку не добавлены.
При последующем встраивании в портал общую шапку и навигацию следует заменить
каркасом портала, сохранив компоненты содержимого.

Требование контраста 4,5:1 имеет приоритет для мелкого текста. В брендбуке
`#059669` на белом даёт 3,77:1, а `#6B7280` на `#F3F4F6` — 4,39:1.
Поэтому текст активного меню использует `#047857` (5,48:1), а вторичный текст
на сером фоне — `#4B5563` из нейтральной палитры. Иконки активного меню
сохраняют исходный `#059669`.

## Где менять дизайн

- `src/contract_checker/ui_layout.py` — общая шапка, навигация и подключение стилей;
- `src/contract_checker/static/ui.css` — токены, типографика, компоненты и адаптив;
- `src/contract_checker/catalog_ui.py` — каталог, загрузка и результаты;
- `src/contract_checker/regulations_ui.py` — нормативные источники;
- `src/contract_checker/static/viwork-logo.png` — оригинальный логотип;
- `src/contract_checker/static/InterVariable.woff2` — локальный Inter 4.1;
- `src/contract_checker/static/Inter-LICENSE.txt` — лицензия шрифта.

Исходный HTML брендбука используется только как визуальная спецификация.
Скрипты и сторонние подключения из файла в приложение не перенесены.
